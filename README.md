# Pizzas y Pastas Rochely

Sitio web de Pizzas y Pastas Rochely, Cancún (Av. Chac Mool, SM 216).

- `index.html`: la página completa (HTML, CSS y JavaScript en un solo archivo).
- `sello.png`: sello "RA" del logotipo.
- `logo-completo.png`: logotipo completo (imagen para compartir en redes).

Para cambiar el número de WhatsApp, edita la constante `WHATSAPP` al final de `index.html`.
